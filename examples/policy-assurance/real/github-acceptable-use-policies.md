**Short version:** We host a wide variety of collaborative projects from all over the world, and that collaboration only works when our users are able to work together in good faith. While using the Service, you must comply with our Acceptable Use Policies, which include some restrictions on content and conduct on GitHub related to user safety, intellectual property, privacy, authenticity, and other limitations.

Capitalized terms used but not defined in these Acceptable Use Policies have the meanings assigned to them in your main agreement with us, including the GitHub Terms of Service or other applicable GitHub agreement.

## 1. Compliance with Laws and Regulations

You are responsible for using the Service in compliance with all applicable laws, regulations, and all of our Acceptable Use Policies. These policies may be updated from time to time.

## 2. User Safety

We do not allow content or activity on GitHub that:

* is unlawful or promotes unlawful activities;
* is libelous, defamatory, or fraudulent;
* harasses or abuses another individual or group;
* threatens or incites violence toward any individual or group; or
* significantly or repeatedly disrupts the experience of other users.

## 3. Intellectual Property, Authenticity, and Private Information

We do not allow content or activity on GitHub that:

* infringes proprietary rights of any party;
* impersonates any person or entity; or
* violates the privacy of any third party, such as by posting another person's personal information without consent.

## 7. Information Usage Restrictions

Researchers may use public, non-personal information from the Service for research purposes, only if publications resulting from that research are open access.

You may not use information from the Service for spamming purposes, including sending unsolicited emails to users or selling personal information.

Your use of information from the Service must comply with the GitHub Privacy Statement.

## 8. Privacy

Misuse of personal information is prohibited.

If you collect any personal information from the Service, you agree that you will only use that personal information for the purpose for which that User has authorized it. You agree that you will reasonably secure personal information and respond promptly to complaints, removal requests, and do-not-contact requests.

## 9. Excessive Bandwidth Use

If GitHub determines bandwidth usage to be significantly excessive, GitHub reserves the right to suspend an Account, throttle file hosting, or otherwise limit activity until usage is reduced.

## 10. Advertising on GitHub

GitHub reserves the right to remove promotional materials or advertisements that, in its sole discretion, violate GitHub terms or policies.

## 11. User Protection

You must not engage in activity that significantly harms other users.

GitHub will interpret its policies and resolve disputes in favor of protecting users as a whole.

### Enforcement

GitHub retains discretion to take action in response to a violation of these policies, including account suspension, account termination, or removal of content.

### Reinstatement and appeal

If content or an account has been disabled or restricted and the user seeks reinstatement or wishes to appeal, GitHub directs the user to its Appeal and Reinstatement process.
