## Interpretation

For these twelve claims, the **publication surface is not authority**. It is a representation that must remain synchronized with the canonical state named in the second column. Where a source, dependency, stable release, contract or evidence condition changes, the last column identifies the class of event that should cause review or reassessment rather than silent inheritance.

A row does not assert that the underlying assurance proposition is universally true. It identifies the bounded evidence and falsification route by which the repository currently defends the proposition.
