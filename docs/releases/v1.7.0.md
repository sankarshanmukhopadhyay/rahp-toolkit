# RAHP Toolkit v1.7.0 — Common Palmfly

**Scientific name:** *Elymnias hypermnestra*  
**Release family:** Assurance Operations and Cross-Spec Execution  
**Compatibility:** additive v1.x release  
**Selected:** 2026-08-27

v1.7.0 strengthens RAHP as an operating assurance system: monitored portfolio changes can be queued, reviewed through explicit analytical modes, preserved as durable evidence, and validated against current-head publication and compatibility contracts.

## Added

- deterministic regression coverage for `rahp`, `security`, `combined`, and multi-target `--all` review execution;
- full DTG cross-spec benchmark execution across **8 declared / 8 runnable compositions**;
- live monitor → persisted state → current-head validation/Pages dispatch acceptance evidence;
- stronger workflow-dispatch contract validation and stale-head protection;
- execution benchmark records for representative DTG, full DTG, and full repository validation;
- release qualification covering the real ZKP queue → combined RAHP/security disposition path.

v1.7.0 introduces a repeatable benchmark surface, but **does not claim an execution-speed improvement**.

Current measured wall times were approximately:

- representative DTG seam: **1.586 s**;

- repository full validation: **11.517 s**.

Earlier like-for-like benchmark evidence did not support a speed-win claim. The release therefore qualifies measurement and coverage improvements, not faster execution.
