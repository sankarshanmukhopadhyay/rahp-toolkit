# RAHP Toolkit v2.2.0 — Common Four-ring

**Scientific name:** *Ypthima huebneri*  
**Release family:** Evidence Production and Realization Assurance  
**Compatibility:** additive product-minor release; existing engine/result/evidence contracts preserved  
**Selected:** 2026-09-07

v2.2.0 extends the qualified autonomous assurance plane from v2.1.0 by making evidence-production obligations and realization/composition evidence explicit, attributable and executable without weakening RAHP's evidence-conservative terminal semantics.

## Product boundary

The release adds a first-class path from an identified assurance gap to a durable evidence or remediation obligation:

```text
assessment proposition
→ evidence/model/remediation gap
→ semantic assurance obligation
→ accountable owner surface
→ evidence producer / remediation path
→ attributable evidence + provenance
→ RAHP reconciliation
→ terminal conclusion or durable residual
```

The important distinction is that RAHP can now model and execute more of the work required to close evidence gaps while still refusing to infer success from missing runtime evidence.

## Added and qualified since v2.1.0

- `rahp-assurance-obligation/v1` with deterministic semantic obligation identity;
- explicit owner surfaces and artifact-to-produce contracts for evidence acquisition, model gaps, remediation, upstream action and controller errors;
- registered evidence-producer controller and scheduler;
- evidence provenance routing and bounded reacquisition semantics;
- bounded assurance invariant waves covering authority/actor dependency, evidence topology and human-choice properties;
- assessment-epoch scoping so later portfolio snapshots cannot silently enlarge earlier evidence boundaries;
- current-portfolio source-pinned clean-room execution and durable proposition matrices;
- explicit normative-baseline versus implementation/realization separation;
- executable VDC/VAC delegation-authority non-substitution evidence;
- runtime-evidence residual routing into durable RAHP, DPIP and Interop Lab owners.

## What the qualification demonstrates

- semantic assurance gaps can acquire stable machine-owned obligation identity;
- evidence production and remediation ownership can be routed without creating a new residual for every monitor event;
- current source pins are distinguishable from historical evidence epochs;
- normative convergence can be recorded separately from implementation conformance;
- runtime properties such as actuation, replay and effective correlation remain evidence-required until observed;
- bounded executable PASS can coexist with portfolio-level INDETERMINATE without contradiction;
- residual work can be transferred to durable owners and controller/epoch records can then close.

## Non-regression invariants

1. Missing evidence never becomes PASS.
2. Workflow success remains distinct from assurance success.
3. Component PASS never automatically implies composition PASS.
4. Normative convergence does not imply implementation conformance.
5. Runtime properties require runtime evidence where static evidence cannot establish them.
6. Generic RAHP core remains target-agnostic.
7. Residual obligations require durable accountable owners or explicit terminal disposition.
8. Historical assessment epochs remain immutable provenance rather than current evidence by default.
