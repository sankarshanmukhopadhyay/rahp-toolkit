## Product boundary

RAHP should no longer be understood primarily as a collection of GitHub workflows. Workflows are triggers and transports around a canonical machine-owned assurance lifecycle:

```text
subject/change observation
→ gather
→ subject model
→ materiality
→ bounded RAHP assessment
→ specialist routing when applicable
→ specialist examination
→ durable specialist return
→ RAHP reconciliation
→ residual/action
→ terminal assurance record
```

Repositories are evidence/source containers. The assured subject may be a specification, requirement, protocol surface, cross-specification interaction, composition, flow, implementation, deployment proposition, portfolio or changeset.

## What qualification means

The bounded release statement is:

> RAHP is qualified, within the tested contract and subject boundaries, as a zero-touch autonomous assurance monitoring plane that can fail closed into citable, actionable terminal assurance states without operator lifecycle shepherding.

The success condition is deterministic attributable termination, **not** optimistic conclusions. Valid outcomes include PASS, FAIL, NOT_APPLICABLE, INDETERMINATE/evidence-required, INDETERMINATE/model-gap, upstream-action and defined controller/contract error states.

The DTG protected-access composition legitimately terminated `INDETERMINATE / model-gap`; component evidence was not promoted into a composition PASS. This is expected assurance behavior.

## Non-regression invariants

1. No human-only controller transition.
2. Missing evidence never becomes PASS.
3. Unmapped evidence/model surfaces become deterministic model-gap residuals.
4. Transport failure is retryable machine state.
5. Specialist completion implies a valid returnable result.
6. Replay does not create duplicate assessment identity.
7. New source pins create reassessment lineage.
8. Evidence classes remain distinct.
9. Component PASS never automatically implies composition PASS.
10. Generic RAHP core contains no target-specific controller logic.
11. Human and machine terminal records represent materially equivalent facts.
12. Material findings identify actionable remediation surfaces and preserve human-harm traceability where applicable.
