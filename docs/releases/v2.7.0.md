## Release scope

This release consolidates post-v2.6 maintenance of assessment ownership, routing and onboarding, alongside optional experimental sociotechnical and reasoning profiles. The stable v2.6 full-stack assurance contract remains the compatibility baseline.

- Assessment and queue ownership reliability, including large issue-queue handling.
- Standalone specification examination and GitHub Pages adoption guidance.
- Optional R1 structural evidence adequacy, R2 temporal applicability/provenance and R3 reproducibility/challenge declarations.
- Synthetic worked examples and an independent-consumer exercise kit.

## Assurance and compatibility

Compatibility remains `rahp-engine-contract-v1` revision 1.3, normalized result schema 1, and `rahp-evidence-retention-v1`. R1–R3 are **optional experimental profiles**, not terminal RAHP assurance, authenticated historical authority or independently reproduced outcomes. Independent adoption remains **NOT_YET_TESTED**. Missing evidence never becomes PASS.
