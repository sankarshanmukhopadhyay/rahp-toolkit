## How to independently audit the original archived evidence

Download the eight exact GitHub Actions artifact ZIP files by the IDs in the table (the GitHub CLI or Actions UI can obtain these). The expected basename is `github-actions-artifact-<artifact-id>.zip`. Place them into one directory and execute:

```bash
python3 tools/validate_eight_controller_transfers.py
python3 -m unittest tests.test_eight_controller_transfers -v
python3 tools/validate_eight_controller_transfers.py --archive-dir /path/to/eight-archives
```

The first check validates immutable inventory/disposition shape, uniqueness, proper owners, false-PASS protection and exact row counts. The last command recomputes **SHA-256 of each original routing.json**, checks snapshot identity and every route/outcome against the ledger, verifies combined child results were actually published, refuses unknown or unhandled DPIP event files, and demands exactly the 54-ID union. It also rejects any non-release change that the original snapshot classified no-action unless that anomaly is explicitly corrected.

**Closure rule:** An administrative controller may be closed only after owner comments, evidence/route checks and exception judgments are recorded. A closed controller does not resolve its successor's assurance issues. New snapshots must be treated independently, not assumed superseded.

**Privacy and human authority:** no proof of a private retention regime, governing VTI conformance, independent human sign-off or deployment/runtime controls is implied. Any new composition-specific privacy evidence must be referred through the established RAHP→DPIP path.
