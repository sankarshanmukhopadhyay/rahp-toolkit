# Support

Use GitHub Issues for reproducible toolkit defects, documentation problems, assurance-model questions, interoperability/composition findings, and bounded feature proposals. Include the affected version/revision, expected and observed behaviour, and relevant evidence or fixtures.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

RAHP owns its method, routing/reconciliation machinery, schemas and toolkit evidence semantics. Normative authority for assessed external specifications/implementations remains with those projects; RAHP findings do not redefine them.
